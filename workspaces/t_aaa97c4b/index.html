Framework Integration

React Integration

Hermes provides first-class React support with typed components and hooks.

Installation

npm install @hermes-design-system/core @hermes-design-system/react
# or
yarn add @hermes-design-system/core @hermes-design-system/react

Setup

// main.tsx or App.tsx
import '@hermes-design-system/core/dist/tokens.css';
import '@hermes-design-system/react/dist/components.css';

import { HermesProvider, Button, Card } from '@hermes-design-system/react';

function App() {
  return (
    <HermesProvider theme="light">
      <Card>
        <h2>Welcome to Hermes</h2>
        <Button variant="primary">Get Started</Button>
      </Card>
    </HermesProvider>
  );
}

Using Design Tokens

import { tokens } from '@hermes-design-system/core';

// Access tokens programmatically
const primaryColor = tokens.color.brand.primary.value;
const spacing = tokens.spacing[4].value;

// Or use CSS custom properties directly
// var(--color-primary), var(--spacing-4)

Dark Mode

import { useTheme } from '@hermes-design-system/react';

function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === 'light' ? '🌙' : '☀️'}
    </button>
  );
}

Customization

// Override tokens via CSS custom properties
// or extend the theme
import { createTheme } from '@hermes-design-system/react';

const customTheme = createTheme({
  color: {
    brand: {
      primary: '#FF6B35',
    },
  },
});

Vue Integration

Vue 3 composables and components for seamless integration.

Installation

npm install @hermes-design-system/core @hermes-design-system/vue
# or
yarn add @hermes-design-system/core @hermes-design-system/vue

Setup

// main.ts
import { createApp } from 'vue';
import Hermes from '@hermes-design-system/vue';
import '@hermes-design-system/core/dist/tokens.css';
import '@hermes-design-system/vue/dist/components.css';

import App from './App.vue';

const app = createApp(App);
app.use(Hermes);
app.mount('#app');

<link rel="stylesheet" href="https://cdn.hermes-ds.com/core/components.css">

npm install @hermes-design-system/core

<button class="btn btn-secondary">Secondary</button>

  <div class="card-header"><h4>Card Title</h4></div>
  <div class="card-body">Content here</div>
</div>

<!-- Alerts -->

  <strong>Success!</div>

JavaScript API

// Initialize Hermes
const hermes = Hermes.init({
  theme: 'light',
  prefix: 'hermes',
});

// Theme management
hermes.theme.set('dark');
hermes.theme.toggle();

// Toast notifications
hermes.toast.success('Changes saved!');
hermes.toast.error('Something went wrong');
hermes.toast.info('New update available', {
  duration: 5000,
  dismissible: true,
});

// Modal
const modal = hermes.modal.open({
  title: 'Confirm',
  content: 'Are you sure?',
  onConfirm: () => console.log('Confirmed'),
});

Migration Guide

Upgrading between versions? Follow these guides to ensure a smooth transition.

v0.x → v1.0.0

This is the first stable release. If you were using the beta version, here are the key changes:

  • Token names have been standardized (e.g., primary-color → color-primary)
  • Component class names now use BEM convention
  • Removed deprecated legacy-button component
  • CSS custom properties now use --hermes- prefix by default
Migration Script 
# Automated migration with codemod
npx @hermes-design-system/codemod v1.0.0 ./src

# Or manually replace:
# .btn-primary → .btn.btn-primary
# .card-shadow → .card.card-elevated
# var(--primary) → var(--color-primary)
