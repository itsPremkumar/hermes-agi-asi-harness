# Hermes AGI/ASI Harness — Documentation

This directory contains the project documentation.

## Files

- **README.md** — Project overview, architecture, quick start, and design principles.
- **SETUP.md** — Installation, configuration, and troubleshooting guide.
- **QUICKSTART.md** — Concise getting-started checklist.
- **IMPROVEMENTS.md** — Gap analysis and prioritized improvements backlog.
- **README_RUNTIME.md** — Runtime-specific notes (kept for historical context).

## Notes

- `README.md`, `SETUP.md`, and `QUICKSTART.md` are kept as separate files because each serves a distinct audience (newcomers vs. integrators vs. operators).
- `IMPROVEMENTS.md` tracks the technical-debt and feature-gap backlog; this file is the authoritative source for outstanding work.
- `README_RUNTIME.md` is preserved for historical context but is superseded by `README.md`.
